This repository is a growing, well-organized anthology of algorithmic challenges implemented from scratch in **C++17**. It covers a wide spectrum — from foundational math and sorting to dynamic programming, graph traversal, and advanced data structures.

Whether you're:

## ⚙️ Getting Started

### Prerequisites

- A C++ compiler supporting **C++17** or later
  - **GCC** 9.0+ → `g++ --version`
  - **Clang** 10.0+ → `clang++ --version`
  - **MSVC** 2019+ on Windows

### Clone the Repository

```bash
git clone https://github.com/Aditya152602/algorithmic-challenges-cpp.git
cd algorithmic-challenges-cpp
```

### Compile & Run Any Solution

```bash
# Using GCC
g++ -std=c++17 -O2 -Wall -o solution "Two Sum/solution.cpp"
./solution

# Using Clang
clang++ -std=c++17 -O2 -Wall -o solution "Two Sum/solution.cpp"
./solution
```

> 💡 Replace `"Two Sum/solution.cpp"` with the path to whichever problem you'd like to run.

## 🤝 Contributing

All contributions are warmly welcomed — new solutions, optimisations, documentation fixes, or anything in between!

1. **Fork** this repository
2. **Create** a feature branch:
   ```bash
   git checkout -b feature/algorithm-name
   ```
3. **Add** your solution in a clearly named folder with a descriptive filename
4. **Commit** with a clear message:
   ```bash
   git commit -m "Add: <Algorithm Name>"
   ```
5. **Push** to your fork:
   ```bash
   git push origin feature/algorithm-name
   ```
6. **Open a Pull Request** and describe what you've added 🚀

### Guidelines
- Keep code clean, readable, and well-commented
- Each solution should be self-contained in its own folder
- Prefer standard C++17 features and avoid unnecessary dependencies
